# Krrete-BackEnd
Respositorio en el cuál se alojará el desarrollo del Back End para la app movil y web de Krrete

## Firebase Auth

Este backend usa Firebase Admin para verificar tokens y administrar usuarios de Auth.

> Importante: el proyecto Firebase usado en el frontend y en el backend debe ser el mismo. El token emitido por el frontend solo puede verificarse correctamente si el backend carga la misma cuenta de servicio de Firebase.
